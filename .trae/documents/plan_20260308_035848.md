## Prometheus + Grafana 集成计划

### 1. 创建 Docker Compose 配置
- 创建 `docker-compose.yml` 部署 Prometheus 和 Grafana 服务
- 配置网络和数据持久化

### 2. 创建 Prometheus 配置
- 创建 `prometheus/prometheus.yml` 配置文件
- 配置抓取任务（包括本地exporter和K8S服务）
- 配置服务发现和scrape间隔

### 3. 创建 K8S 流量 Exporter
- 创建 `prometheus/k8s_traffic_exporter.py` 用于抓取K8S服务流量数据
- 使用 Kubernetes Python客户端获取服务指标
- 暴露Prometheus格式的指标

### 4. 创建 Grafana 配置
- 创建 `grafana/provisioning/datasources/datasource.yml` 配置Prometheus数据源
- 创建 `grafana/provisioning/dashboards/dashboard.yml` 配置dashboard自动加载
- 创建 `grafana/provisioning/dashboards/k8s_traffic.json` 示例dashboard

### 5. 创建 K8S 部署配置（可选）
- 创建 `k8s/deployment.yml` 用于在K8S集群中部署exporter
- 创建 `k8s/service.yml` 暴露exporter服务
- 创建 `k8s/servicemonitor.yml` 用于Prometheus Operator

### 6. 更新 requirements.txt
- 添加必要的Python依赖（prometheus_client, kubernetes等）

### 架构说明
```
┌─────────────────┐    ┌─────────────────┐    ┌─────────────────┐
│   Grafana       │◄───│   Prometheus    │◄───│  K8S Exporter   │
│   (UI: 3000)    │    │   (UI: 9090)    │    │  (Port: 9000)   │
└─────────────────┘    └─────────────────┘    └─────────────────┘
                                                      │
                                                      ▼
                                              ┌─────────────────┐
                                              │  K8S API Server │
                                              │  (流量数据源)    │
                                              └─────────────────┘
```
